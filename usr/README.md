# Snake Game

A cross-platform Flutter implementation of the classic Snake game, originally written in Python/Pygame.

## Features
- **Classic Gameplay**: Eat the red food squares to grow your snake and increase your score.
- **Cross-Platform Input**: 
  - Desktop/Web: Use Arrow Keys to navigate.
  - Mobile: Swipe anywhere on the screen to change direction.
- **Responsive Layout**: The game board natively scales up and down to fit mobile devices, tablets, and desktop windows while keeping its aspect ratio intact.

## Tech Stack
- Flutter (Dart)
- Cross-platform Timer-based rendering loop

## How to Run

1. Make sure you have Flutter installed.
2. Run `flutter pub get`.
3. Start the game on your preferred platform:
   - Web: `flutter run -d chrome`
   - Desktop: `flutter run -d windows` / `macos` / `linux`
   - Mobile: `flutter run`
